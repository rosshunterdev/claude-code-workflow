Quiz me on concepts that came up in this session. $ARGUMENTS can name a topic to focus on.

1. Pick 3-5 concepts that came up this session and are worth knowing beyond this
   project (e.g. why a pattern exists, how a tool works). Skip trivia like file names.
2. Ask ONE question at a time and wait for my answer. Mix the types:
   - explain it in my own words
   - predict what happens if X changes
   - spot what's wrong in a short snippet
3. After each answer: say right / partly / not quite, then give the key point in
   1-2 sentences, with an analogy if I missed it.
4. At the end: list each concept with a ✓ or ✗, plus one line on what to revisit.

No long lectures. If I say "skip", move on.
